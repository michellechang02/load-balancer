Thank you for your interest in contributing to this load balancer simulation.

Quick start
- Fork the repository and open a pull request against `main`.
- Keep changes small and focused.
- Run `make` and ensure the build completes before submitting.

Code style
- C++17 is used across the project. Keep changes consistent with existing style.

Testing
- Add small, self-contained tests or smoke checks where applicable.

Communication
- Use clear commit messages and reference related issues in PR descriptions.
